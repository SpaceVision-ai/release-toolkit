# @spacevision-ai/release-toolkit-dart

Dart/Flutter 레포용 릴리즈 자동화 adapter.

- `config/releaserc-base.cjs` — semantic-release 설정 (`@semantic-release/exec` 기반 pubspec.yaml 범프)
- `scripts/bump-pubspec.mjs` — pubspec.yaml version + build number 자동 교체

사용법은 [ONBOARDING-dart.md](../../docs/ONBOARDING-dart.md) 참고.
